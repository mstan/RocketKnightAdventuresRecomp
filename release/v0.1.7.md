# Rocket Knight Adventures Recomp v0.1.7

Windows x64 ZIP and Linux x86_64 AppImage. Bring your own **Rocket Knight
Adventures (USA)** ROM (CRC32 `A6EFEC47`); no ROM is included.

The stage-1 tank boss bridge now continues its authored curved fence into the
widescreen margins. Previously, each margin repeated one sloped 32-pixel block,
making the rail sawtooth and causing a visible height jump beside the boss.
The native 320-pixel play area is unchanged. This release also includes the
stage-1 fire launcher and boss chamber fixes from v0.1.6.

Validation replayed the tester's tank boss save for 120 frames in native,
16:9 and 32:9. At five checkpoints, the native play area and guest RAM matched
exactly. The full renderer regression and packaged Windows/Linux checks passed.

Extract the Windows ZIP and run `RKARecomp.exe`, or run the Linux AppImage in a
writable folder. Use the launcher's ROM picker or pass the USA ROM path on the
command line. Enable **Mods > Widescreen** and choose **Adaptive (fit window)**
or a fixed aspect ratio. Resize an adaptive window to the shape you want.
