# Rocket Knight Adventures Recomp v0.1.0

Windows x64 ZIP and Linux x86_64 AppImage. The repository remains private.
Bring your own **Rocket Knight Adventures (USA)** ROM (CRC32 `A6EFEC47`);
no ROM is included.

## Changes

- RKA-specific custom renderer with Adaptive (fit window), 16:9, 21:9 and 32:9.
- Expanded Spawn Range is the default widescreen enemy activation mode;
  Original Spawn Range preserves the original screen's encounter timing.
- Corrected background parallax at stage boundaries and extended the HUD's
  gold frame across the top of the wider view.
- Updated the existing Genesis engine and launcher submodule pins.
- Added Windows and Linux build/package scripts adapted from Super Mario World,
  production version stamps, dependency checks, license notices and checksums.

Enable widescreen through **Mods > Widescreen** in the launcher.

## Validation and limits

The packaged Windows and Linux builds match the previously tested renderer's
pixels, RAM and VRAM in seven scripted captures: castle native/wide, stage 1
native/Original/Expanded, and stage-start idle/walking. Original mode preserves
native RAM/VRAM and viewport pixels; Expanded activates more enemies (15 versus
10 in the test scene). HUD framing and background parallax checks pass.

Windows runs with a system-only PATH and verified DLL dependencies. Linux
passes AppImage state, ROM discovery and relocation tests, plus graphical
launcher/Mods checks under Xvfb with software OpenGL on Ubuntu 24.04 WSL.

Linux targets Ubuntu 24.04 or compatible distributions; older systems and
Steam Deck are unvalidated. A complete later-stage widescreen playthrough is
still pending. The attract demo can diverge from its recorded inputs.

The shared Genesis engine source was not changed for this release.

## Running

- **Windows:** extract the whole ZIP and run `RKARecomp.exe`.
- **Linux:** place the AppImage in a writable folder, `chmod +x` it and launch.
  Use `--appimage-extract-and-run` if FUSE is unavailable. Put your raw USA ROM
  beside it as `rka.bin`, or use the launcher's ROM picker.

Preserve `settings.ini`, `rka-video.ini`, and `rom-RKA.cfg` when upgrading.
See the packaged README and license notices. `SHA256SUMS.txt` covers both assets.
