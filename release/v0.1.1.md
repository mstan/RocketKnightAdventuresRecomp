# Rocket Knight Adventures Recomp v0.1.1

Windows x64 ZIP and Linux x86_64 AppImage. The repository remains private.
Bring your own **Rocket Knight Adventures (USA)** ROM (CRC32 `A6EFEC47`);
no ROM is included.

## Changes

- Corrected castle scenery parallax at widescreen level boundaries. The castle
  follows the wider camera while its independent animation is preserved.
- Replaced the large empty HUD side panels with slim gold trim and scenery
  beneath. The original HUD counters remain centered.
- Retained Adaptive (fit window), fixed widescreen ratios, and both enemy
  activation options. Expanded Spawn Range remains the default.

Enable widescreen through **Mods > Widescreen** in the launcher.
The shared Genesis engine and launcher source and submodule pins are unchanged.

## Validation and limits

The Windows and Linux packages match the approved renderer's pixels, RAM and
VRAM in seven scripted captures covering the castle, stage 1, both spawn modes,
and stage-start idle/walking. Native viewport and Original-mode simulation
parity, castle/background stability and scenery beneath the HUD trim pass.
The renderer also passed adaptive resizing and 48:9 edge checks before approval.

Windows runs with a system-only PATH and verified DLL dependencies. Linux
passes the AppImage state, ROM discovery and relocation checks.
Linux targets Ubuntu 24.04 (glibc 2.39) or compatible installations with OpenGL;
older distributions and Steam Deck remain unvalidated. A complete later-stage
widescreen playthrough is pending. The attract demo can diverge from its
recorded inputs.

## Running

- **Windows:** extract the whole ZIP and run `RKARecomp.exe`.
- **Linux:** place the AppImage in a writable folder, `chmod +x` it and launch.
  Use `--appimage-extract-and-run` if FUSE is unavailable. Put your raw USA ROM
  beside it as `rka.bin`, or use the launcher's ROM picker.

Preserve `settings.ini`, `rka-video.ini`, and `rom-RKA.cfg` when upgrading.
See the packaged README and license notices. `SHA256SUMS.txt` covers both assets.
