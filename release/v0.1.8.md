# Rocket Knight Adventures Recomp v0.1.8

Windows x64 ZIP and Linux x86_64 AppImage. Bring your own **Rocket Knight
Adventures (USA)** ROM (CRC32 `A6EFEC47`); no ROM is included.

Expanded Spawn Range no longer leaves wrapped enemy and cart fragments in the
original play area. In widescreen, distant actors can be active more than 512
pixels from the native sprite origin; their Genesis hardware sprite X value
wrapped back into the center. The renderer now keeps those hardware pieces out
of the center while drawing the complete actor at its true widescreen position.
This fixes the extra soldier in the stage-1 fire corridor and half carts in
the rail-section attract demo.

The fix was checked against exact-frame captures from v0.1.7 in both scenes.
The native 320-pixel presentation and Original Spawn Range are unaffected.

Extract the Windows ZIP and run `RKARecomp.exe`, or run the Linux AppImage in a
writable folder. Use the launcher's ROM picker or pass the USA ROM path on the
command line. Enable **Mods > Widescreen**, select **Adaptive (fit window)**
or a fixed aspect ratio, and select **Expanded Spawn Range** under enemy
activation. Resize an adaptive window to the shape you want.
