# Rocket Knight Adventures Recomp v1.0.1

This Windows x64 and Linux x86_64 update retains version 1.0's Adaptive
widescreen defaults and existing saved choices, and adds the approved shared
runtime performance and save-state safety fixes.

- Skip background composition for discarded replay frames while retaining
  sprite limits/collision flags, VDP ordering and CPU/audio scheduling.
- Reject malformed current-build quickstates without changing the running game.
- Use the clean game name in launcher and gameplay captions; keep version and
  build identity in diagnostics and About.

The qualified Windows dense replay workload used 15.7% fewer total process
cycles. Ordinary gameplay measured neutral within matching A/A controls. RKA
supports rewind and local replay qualification; this release does not add netplay.
Both native and 16:9 routes matched reference guest state, pixels and captured
audio, and the owner accepted the combined gameplay/audio playtest.

Supply your own USA ROM (CRC32 `A6EFEC47`). No ROMs, donor assets, saves or user
settings are distributed. Native progress files remain separate from disposable,
build-specific quickstates. Existing version 1.0 renderer limitations still apply.
