# Rocket Knight Adventures Recomp v0.1.3

Windows x64 ZIP and Linux x86_64 AppImage. Bring your own **Rocket Knight
Adventures (USA)** ROM (CRC32 `A6EFEC47`); no ROM is included.

## Changes

- The flying city's 256-pixel background no longer repeats across very wide
  windows. Scenery beyond the original view fades into the scene's own colors;
  the original play area and moving characters remain visible.
- The Continue screen and other presentation screens stay centered instead of
  repeating their text and decorations into the side margins.
- Expanded Spawn Range remains available and enabled by default.

## Validation

The renderer regression replays the flying city in native and 1392-pixel
widescreen modes and the reported Continue-screen save at the same width. It
checks original-view pixels, RAM/VRAM parity, and the side margins. Existing
castle, HUD, adaptive-resize, and enemy-activation checks also passed.

## Running

Extract the Windows ZIP and run `RKARecomp.exe`, or run the Linux AppImage in a
writable folder. Use the launcher's ROM picker or pass the USA ROM path on the
command line. Enable widescreen under **Mods > Widescreen**.

Keep existing settings files when upgrading. The packages contain no game ROM.
