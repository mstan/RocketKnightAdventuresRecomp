# Rocket Knight Adventures Recomp v1.0.0

The first stable release. Windows x64 ZIP and Linux x86_64 AppImage. Bring
your own **Rocket Knight Adventures (USA)** ROM (CRC32 `A6EFEC47`); no ROM is
included.

Version 1.0 marks the port as stable after the v0.1 playtest series. It
runs the game natively on PC with:

- **Adaptive widescreen** across all seven stages, including vehicle
  sections, boss arenas and cutscenes. It is now **on by default** in
  Adaptive (fit window), which follows the window as you resize it; fixed
  16:9, 21:9 and 32:9 modes remain. Turn it off under **Mods > Widescreen**
  for the original 4:3 view. A choice saved by an earlier version is kept.
- **Enemy activation** choice: Expanded Spawn Range (default) or the original
  timing.
- **Rewind** through recent play and **visual save states** with nine
  previewed slots and direct shortcuts.
- **Launcher** with ROM selection, keyboard and controller remapping, and
  video, audio and rewind settings.
- **Built-in mods:** Start Stage, Infinite Lives, Infinite Health and
  Invincible.

Gameplay code is unchanged from v0.1.14: the generated native code is
identical and all 41 authored intro, stage and ending area IDs still match
the interpreter-backed baseline across 246 RAM/screenshot captures in
6000-frame 32:9 routes with strict stack checking. This assisted survey does
not certify every boss victory or an unassisted complete playthrough.

Extract the entire Windows ZIP and run `RKARecomp.exe`, or run the Linux
AppImage in a writable folder, then select your ROM. Keep `settings.ini`,
`rka-video.ini`, `rom-RKA.cfg` and your saves when upgrading. Save states
require the same build and configuration.

Known limitations: a few arena and cutscene margins repeat or mirror
background details (later machine room, Earth transition), some boss artwork
clips at arena edges, a flying boss can briefly show a thin propeller slice
at the extreme edge, and the attract demo can diverge from its recorded
inputs.
