# Rocket Knight Adventures Recomp v0.1.4

Windows x64 ZIP and Linux x86_64 AppImage. Bring your own **Rocket Knight
Adventures (USA)** ROM (CRC32 `A6EFEC47`); no ROM is included.

## Changes

- Fixed stage 1 apples appearing to slide into the ultrawide view. Expanded
  Spawn Range keeps the real apples visible at their world positions; their
  nine-bit hardware sprite coordinates no longer create duplicate apples
  512 pixels away in the original viewport.
- The v0.1.3 flying-city and Continue-screen widescreen fixes remain included.

## Validation

Replayed the reported slot 1 save at 1392 logical pixels and walked right for
150 frames. All six real apples stayed active, while the wrapped copies were
absent. Original Spawn Range retained native RAM, VRAM and centered pixels.
The renderer regression also covered expanded activation, HUD, castle,
adaptive resizing, the flying city and the Continue screen.

## Running

Extract the Windows ZIP and run `RKARecomp.exe`, or run the Linux AppImage in a
writable folder. Use the launcher's ROM picker or pass the USA ROM path on the
command line. Enable widescreen under **Mods > Widescreen**.

Keep existing settings files when upgrading. The packages contain no game ROM.
