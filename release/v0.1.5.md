# Rocket Knight Adventures Recomp v0.1.5

Windows x64 ZIP and Linux x86_64 AppImage. Bring your own **Rocket Knight
Adventures (USA)** ROM (CRC32 `A6EFEC47`); no ROM is included.

## Changes

- Widescreen now covers the whole game. The stage 5 boss, cutscenes, the
  stage 6 shooter, the airship boss, the stage 7 corridors and final boss,
  and the stage 1 boss no longer fall back to 4:3.
- Fixed side-margin glitches while scrolling. Stage-specific edge strips that
  copied characters into the margins are gone; locked boss rooms continue
  their own walls, and vehicle rides draw their real scenery.
- Enemy waves that enter at fixed screen edges (shooter waves, rail-ride
  carts, flying enemies) now enter from the wider edge in Expanded Spawn Range.
- New playtest cheats, each its own mod under **Mods > Cheats**: Start Stage
  (begin a new game at stage 1-7, then continue normally), Infinite Lives,
  Infinite Health and Invincible.
- Much more of the game now runs as recompiled native code instead of the
  interpreter fallback.

## Validation

Replayed all reported saves from stages 1-7 in native and 16:9, booted every
stage area with automated input, and confirmed the newly recompiled code
leaves game RAM byte-identical after 3600 frames in every area. Original
Spawn Range kept native RAM, VRAM and centered pixels; the renderer
regression covered activation, HUD, castle, adaptive resizing, the flying
city, the Continue screen and stage 1 apples. An owner playtest covered
stages 4 and 6 with Start Stage.

## Running

Extract the Windows ZIP and run `RKARecomp.exe`, or run the Linux AppImage in a
writable folder. Use the launcher's ROM picker or pass the USA ROM path on the
command line. Enable widescreen under **Mods > Widescreen**.

Keep existing settings files when upgrading. The packages contain no game ROM.
