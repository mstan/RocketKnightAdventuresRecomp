# Rocket Knight Adventures Recomp v0.1.6

Windows x64 ZIP and Linux x86_64 AppImage. Bring your own **Rocket Knight
Adventures (USA)** ROM (CRC32 `A6EFEC47`); no ROM is included.

## Changes

- Fixed the stage-1 boss chamber disappearing behind outdoor sky in widescreen.
  The chamber and boss stay visible in the exact native play area at 16:9 and
  32:9, with sky extending into the side margins without repeating the room.
- Moved the stage-1 fire corridor's scripted launcher and linked fire source
  to the expanded right edge. Their flames now enter from that edge instead
  of appearing at the original 4:3 boundary.
- Promoted 13 ROM-validated stage-1 routines from the interpreter fallback to
  recompiled code using the tester's floor coverage and captured execution.
- Corrected the default control descriptions: B jumps; A and C attack and
  charge the rocket pack.

## Validation

Replayed the supplied fire-corridor and boss saves in native, 16:9 and 32:9.
Original Spawn Range kept the 320-pixel play area and guest RAM/VRAM identical
to native; the boss room also stayed identical in Expanded Spawn Range. A
scripted 16:9 run from the supplied boss save defeated the boss and reached
the stage-clear screen. The renderer suite passed adaptive resizing, HUD,
castle parallax, flying city, Continue screen, apple sprites and activation.
Native replay of the new saves remained byte-identical to v0.1.5 after the
new routines were compiled.

## Running

Extract the Windows ZIP and run `RKARecomp.exe`, or run the Linux AppImage in a
writable folder. Use the launcher's ROM picker or pass the USA ROM path on the
command line. Enable widescreen under **Mods > Widescreen**. Existing settings
and saves can be kept when upgrading.
