the Windows x64 package includes the native runner, launcher and dependencies.

against clean 68000 decoding and executed-instruction evidence. Native
coverage gains 252 instruction starts with no previously native code lost.

used only to validate conservative late function entries. The fold tool
now rejects an empty or incorrect generated-code directory before accepting

route frames at 32:9 with expanded spawning and strict stack checking. All

routes. Three late routes still use the validated interpreter floor for
interior callable entries; those entries were not blindly split into new
functions. This assisted survey does not certify every boss victory or an
unassisted complete playthrough.
