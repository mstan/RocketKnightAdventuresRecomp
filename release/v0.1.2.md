# Rocket Knight Adventures Recomp v0.1.2

Windows x64 ZIP and Linux x86_64 AppImage. Bring your own **Rocket Knight
Adventures (USA)** ROM (CRC32 `A6EFEC47`); no ROM is included.

## Changes

- Extended widescreen scene coverage across the supplied stage 1–4 saves,
  including water, fire, castle edges, platforms, and the HUD margins.
- Expanded vehicle enemy creation to cover the visible widescreen edges. The
  **Expanded Spawn Range** option remains the default; **Original Spawn Range**
  preserves original encounter timing.
- Fixed the overlapping 68000 instruction stream that caused the stage 4 boss
  completion to stall with an interior-label dispatch error. Old saves taken
  after that fault may need recovery before replaying the boss transition.

## Validation

The supplied stage 1–4 saves were exercised in native and widescreen modes,
including the recovered stage 4 boss save. Automated video, stage, and package
checks passed. The shared engine change was also checked against Sonic 1, 2,
and 3 & Knuckles attract routes and gameplay input runs.

## Running

Extract the Windows ZIP and run `RKARecomp.exe`, or run the Linux AppImage in a
writable folder. Use the launcher's ROM picker or pass the USA ROM path on the
command line. Enable widescreen under **Mods > Widescreen**.

Keep existing settings files when upgrading. The packages contain no game ROM.
