# Rocket Knight Adventures Recomp v0.1.10

Windows x64 ZIP and Linux x86_64 AppImage. Bring your own **Rocket Knight
Adventures (USA)** ROM (CRC32 `A6EFEC47`); no ROM is included.

This release adds local rewind and a visual nine-slot save-state browser.
**F8** opens the rewind filmstrip; **F7** opens the browser. Use Left/Right
to choose a rewind point, or arrows to choose a save slot; Enter restores,
S saves a selected slot, and Esc cancels. On a controller, Back/View +
right-stick click opens rewind and Back/View + RB opens the browser. Both
overlays pause gameplay and audio. Existing `native_save_N.bin` files remain
compatible; the browser adds thumbnail sidecars for new saves. Rewind depth,
interval and enablement are available in the launcher.

Starting with Widescreen enabled now opens a 16:9 game window, including
Adaptive mode, so the extended scene is visible immediately.

The 16:9 renderer now carries the water tower, castle cutscene wall, lava-room
edges, cannon cutscene terrain, stationary city wall, mecha body and ending
wall into the extra margins. The mecha boss's right edge remains visible as
it moves. A shared-engine fix also keeps the flying-city attract scene free
of repeated wall art at very wide aspect ratios. The supplied save set was
replayed in native and 16:9 modes; the full renderer regression passed.

Extract the Windows ZIP and run `RKARecomp.exe`, or run the Linux AppImage in
a writable folder. Use the launcher's ROM picker or pass the USA ROM path on
the command line. Enable **Mods > Widescreen**, select **Adaptive (fit
window)** or a fixed aspect ratio, and choose **Expanded Spawn Range** under
enemy activation for playtesting.

The reported castle-corridor fire emitter in save 3 still needs a close
playtest. In the supplied save, native and wide runs both emit fire blasts
from beyond the right edge; no missing execution path appeared in the logs.
